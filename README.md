# 🏦 Banking Analytics Dashboard

## 📌 Project Overview

This project presents an end-to-end banking analytics solution using Power BI, SQL, and Python. It focuses on analyzing customer data, loans, and deposits to generate meaningful business insights and support data-driven decision-making.

---

## 🛠️ Tools & Technologies Used

* Power BI (Dashboard & Visualization)
* MySQL (Database & Queries)
* Python (Pandas, Matplotlib for Data Analysis)
* Excel (Dataset)

## 📈 Key Features

* Interactive Power BI dashboard with KPI cards
* Loan vs Deposit analysis
* Customer segmentation insights
* Trend analysis of financial data

---

## 📌 Key Business Insights

* Loan to Deposit Ratio is **116%**, indicating higher loan distribution than deposits
* High-income customers tend to take more loans
* Certain customer segments contribute more to deposits
* Identified trends in customer financial behavior

---

## 🗄️ Database & SQL

* Created a MySQL database: `banking_case`
* Performed data extraction using SQL queries
* Used queries for KPI calculations and analysis

---

## 📂 Project Files

* `banking_data_analysis.ipynb` → Python data analysis
* `banking_dashboard.pbix` → Power BI dashboard
* `banking_data.csv` → Dataset
* `banking_case_queries.sql` → SQL queries

---

## ▶️ How to Use

1. Download the `.pbix` file and open in Power BI Desktop
2. Run the `.ipynb` file in Jupyter Notebook
3. Execute SQL queries in MySQL
